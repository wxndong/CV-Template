{RAG QA Bot for Academic Papers | \highlight{Personal Open-Source Project}}
{\textit{2024.12—2025.03}}
{
  Designed a lightweight hybrid Retrieval-Augmented Generation (RAG) system addressing information overload in academic research, balancing semantic understanding depth and retrieval efficiency.
}{
  \item \highlight{Data Processing}: Cleaned and filtered ~100K papers from Arxiv CS dataset across 6 subfields (CV, AI etc.), generating efficient index files using ColBERTv2.
  \item \highlight{Architecture Design}: Construct a lightweight RAG system based on the Ragatouille framework, with a pipeline comprising a complexity scorer, retriever, text fusion module (integrating queries with Top-k documents), and generator, optimized to balance performance and computational complexity.
